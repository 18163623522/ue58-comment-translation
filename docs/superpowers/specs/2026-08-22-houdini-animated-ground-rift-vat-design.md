# Houdini 动画地裂与 VAT 设计规格

## 目标

在当前 Houdini 场景中新增一个独立、非破坏式的地裂效果网络。地裂从起点向终点推进，整体高度沿推进方向逐渐升高，中央地表呈现地下力量向上顶起后开裂、回落的动画。效果不包含地刺，并为后续 Vertex Animation Texture（VAT）导出保留稳定拓扑。

## 视觉设计

- 地裂沿一条带噪声的纵向路径推进，轮廓自然且不完全对称。
- 起点区域较低、变化较弱；越接近终点，隆起高度和裂缝张力越明显。
- 动画采用“蓄力隆起 → 裂缝推进 → 轻微回弹稳定”的节奏。
- 裂缝中心形成窄幅下陷或分离感，两侧形成较宽的隆起带。
- 不创建尖锐地刺，不使用会突然改变拓扑的碎裂或布尔切割动画。

## Houdini 网络结构

在 `/obj` 下创建独立 Geometry 容器，避免修改现有节点。容器内部采用固定分辨率网格作为基础地面，通过 SOP/VEX 计算以下属性：

1. 沿推进轴的归一化位置 `progress_u`。
2. 带低频噪声偏移的裂缝中心线距离 `crack_dist`。
3. 从起点到终点递增的高度权重 `directional_ramp`。
4. 根据帧数推进的动画遮罩 `anim_mask`。
5. 中央下陷与两侧隆起组合后的最终位移。

所有动画仅修改点位置及可选法线、颜色属性，不增删点或面。

## 动画时序

- 默认时间范围：1–72 帧。
- 推进前沿从起点移动到终点，每个区域在前沿到达前保持静止。
- 前沿到达后先快速隆起，再产生小幅阻尼回弹。
- 关键速度和幅度通过容器参数控制，便于后续调整镜头节奏。

## 可调参数

- 地面长度、宽度与网格分辨率。
- 裂缝宽度、边缘噪声频率和噪声强度。
- 起点高度、终点高度、中央下陷深度。
- 动画开始帧、结束帧、前沿柔化范围与回弹强度。
- 随机种子。

## VAT 兼容约束

- 全动画保持固定点数、固定面数、固定点序和一致拓扑。
- 不使用动态 Remesh、Boolean、RBD 碎裂或按帧删除几何。
- 变形集中在单一输出网格上，输出节点命名清晰，便于接入 SideFX Labs VAT ROP。
- 在最终验证中抽查首帧、中间帧和末帧的几何统计必须一致。

## 验证标准

- Houdini MCP 能稳定连接并操作当前场景。
- 新网络与现有场景隔离，现有节点未被修改或删除。
- 起点到终点的最大隆起高度呈明确递增趋势。
- 时间轴播放时能看到隆起前沿推进和轻微回弹。
- 效果中不存在地刺几何。
- 首帧、中间帧和末帧的点、面、顶点数量完全一致。
- 输出节点强制 Cook 无错误，网络扫描无错误节点。

## 非目标

- 本阶段不制作材质、烟尘、碎石、RBD 或最终灯光渲染。
- 本阶段不执行 VAT 纹理烘焙和游戏引擎导入；只保证当前动画网络满足后续 VAT 的拓扑要求。
