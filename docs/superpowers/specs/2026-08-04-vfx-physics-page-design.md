# 特效物理知识互动长文页 — 设计文档

日期：2026-08-04
状态：已与用户对齐，待实现

## 1. 目标与读者

一个面向 **VFX 特效师 / 技术美术（TA）** 的物理知识梳理页面，主题：**特效中用到的物理知识**。

- 从最基础的物理讲起，循序渐进到高阶模拟原理
- 核心写作约束：**大部分人看得懂**（先直觉后公式）、**有兴趣学下去**（现象开场、演示好玩）
- 每个知识点落到特效工具语境（Niagara / Houdini 里对应的概念和参数）

语言：中文正文，专业术语保留英文（如 Drag、Curl Noise、Navier-Stokes）。

## 2. 交付形态

- **单个自包含 HTML 文件**，产出路径：`vfx-physics/index.html`
- **完全离线**：无 CDN、无外部字体、无网络请求；CSS/JS/WebGL 全部内联
- 双击即可在浏览器打开使用
- 字体：系统字体栈（衬线标题：Georgia, "Times New Roman", "Noto Serif SC", "SimSun", serif；正文：系统无衬线栈 + "Noto Sans SC", "Microsoft YaHei" 兜底）

### 3.2 模块内容模板（每模块统一五段式）

每个模块严格按以下顺序组织，保证循序渐进的节奏：

1. **现象**（约 100 字）— 生活化或影视中的具体现象开场，提出疑问。例：*"雨滴从两千米高空落下，如果只受重力，落地时速可达 200 m/s——足以击穿头骨。但现实中的雨是温柔的。中间发生了什么？"*
2. **直觉**（约 150 字）— 用比喻把核心机制讲清，零公式。
3. **原理**（约 200-300 字）— 核心概念 + 关键公式。公式出现时必须逐项解释符号含义和直觉对应；优先用文字叙述，公式只放真正关键的那一两个。
4. **交互演示** — WebGL 演示卡片（见 §4），卡片上方一句引导语（如"试试把阻力系数拉到最大，看雨滴如何悬停"）。
5. **应用到特效**（约 100 字）— 该物理在特效工具中的对应：Niagara / Houdini 里的节点或参数名，以及特效师常踩的直觉误区。

写作红线：
- 禁止堆砌教科书式推导；每个公式必须有"人话翻译"
- 比喻必须贴近日常（电梯、滑板、吹蜡烛），不用读者不熟悉的喻体
- 每模块结尾不写"总结"段，直接收在应用段

## 4. WebGL 交互演示

### 4.1 技术方案

- **原生 WebGL2**（回退 WebGL1），不引入 three.js 或任何第三方库（离线约束）
- 自研一个小型共享渲染框架（约 300-500 行），提供：
  - 点精灵粒子渲染（位置/颜色/大小 buffer，逐帧 CPU 物理积分后上传）
  - 全屏四边形 pass（供 shader 类演示使用：流体、Metaball、黑体辐射）
  - 线段渲染（轨迹、弹簧链、闪电枝干）
  - 画布尺寸自适应（devicePixelRatio 感知，ResizeObserver）
- 每个演示 = 一个独立 `Demo` 对象（init / update(dt, params) / render），注册到统一调度器
- **流体类演示（07/08）**：CPU 端粗网格求解（约 96×96 Stable Fluids），每帧把速度/温度场上传为 GPU 纹理渲染——避开浮点渲染目标（float FBO）的兼容性深坑，96×96 的 CPU 开销在中端机器上可忽略
- **懒初始化**：IntersectionObserver，进入视口才创建 GL context 并开始 rAF 循环；离开视口超过一屏暂停 rAF
- **活跃演示上限 2 个**：演示卡片高度约 400px，常规视口最多两个同屏；超过上限时暂停最早激活的演示。粒子规模按中端核显 60fps 预算设计（见 §4.3 各演示的量级）

### 4.2 参数面板

每个演示卡片下方一组滑杆（`<input type="range">`，杂志风样式），2-4 个参数，实时生效。每个滑杆有标签和当前数值。另配一个"重置"按钮恢复默认参数。

### 4.3 十五个演示清单

| # | 演示名 | 内容 | 可调参数 |
|---|---|---|---|
| 01 | 抛体运动 | 粒子以初速发射，画出轨迹；可切换"有/无重力"对比 | 初速度、发射角度、重力强度 |
| 02 | 力的叠加 | 2D 沙盒中一个物体受重力+风力+持续推力，看加速度响应 | 质量、风力、推力 |
| 03 | 终端速度 | 两组粒子同时下落（有/无阻力对比），速度-时间小曲线 | 阻力系数、质量、重力 |
| 04 | 弹性碰撞 | 2D 圆盘互撞+撞墙，动量守恒可视化 | 恢复系数、重力、数量 |
| 05 | Curl Noise | 数千粒子沿无散度噪声场流动 | 噪声尺度、强度、流速 |
| 06 | 弹簧质点链 | 一端固定的弹簧链受初始扰动，观察振动传播与衰减 | 刚度、阻尼、质量 |
| 07 | 烟雾模拟 | 网格法流体（Stable Fluids），底部发射器持续注入烟雾 | 涡度增强、耗散、注入力度 |
| 08 | 火与浮力 | 温度场驱动上升的火柱（基于 07 的求解器加温度项） | 浮力强度、温度耗散、扰动 |
| 09 | 黑体辐射与吸收 | shader：温度→颜色渐变条 + 一束光穿过可调密度的介质 | 温度、介质密度、光程 |
| 10 | 断裂 | Voronoi 预碎的板，受冲击后碎块按动量飞散 | 冲击强度、碎块数、重力 |
| 11 | 闪电 | 中点位移 + 分支递归生成闪电，随机重击闪烁 | 分枝概率、抖动量、辉光强度 |
| 12 | 爆炸冲击波 | 中心爆炸：冲击波环扩散 + 粒子按 1/r² 衰减被推开 | 爆炸能量、衰减率、粒子数 |
| 13 | 沙堆 | 2D 元胞自动机落沙，形成安息角 | 落沙速率、颗粒大小 |
| 14 | 液滴融合 | Metaball shader，多个液滴游动、靠近时融合 | 表面张力阈值、液滴数、速度 |
| 15 | 轨道引力 | 中心恒星 + 发射探测器，N 体引力下的轨道 | 恒星质量、初速度、发射角度 |

### 4.4 演示容错

- WebGL 不可用（或 context 创建失败）时：演示区显示样式化的静态占位框 + 一句文字说明"此演示需要支持 WebGL 的浏览器"
- 物理积分使用半隐式欧拉 + 帧时间钳制（dt ≤ 32ms），避免后台切回时爆掉

## 5. 视觉设计规范（科学杂志 · 编辑风）

### 5.1 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#FAF7F0` | 页面底色（暖纸白） |
| `--ink` | `#1A1815` | 正文与标题 |
| `--ink-soft` | `#4A453D` | 次要文字、图注 |
| `--accent` | `#B4552D` | 唯一强调色（砖红）：章节号、链接、高亮、滑杆拇指 |
| `--hairline` | `#D8D2C4` | 分隔细线、演示卡片边框 |
| `--demo-bg` | `#12100D` | 演示画布背景（深色，让粒子/光效清晰） |

演示画布用深色底（纸面上的"暗窗"），与正文亮底形成对比，也让光效类演示观感正确。

### 5.2 排版

- 正文列宽 `68ch`，居中；正文 17px / 行高 1.8
- 标题层级：H1 页面名（衬线 40px+）、层扉页标题（衬线 32px）、模块标题（衬线 24px，配砖红 `Chapter NN` 小字标）
- 公式：衬线斜体风格块，居中，浅纸色底 + 细边框
- 正文与演示卡片间距 ≥ 48px；模块之间间距 ≥ 96px
- 段落不用首行缩进，段间距 1em

### 5.3 动效（克制）

- 模块标题、演示卡片进入视口时轻微淡入上移（300ms ease-out），尊重 `prefers-reduced-motion`（关闭时直接显示）
- 目录当前项高亮切换用 200ms 过渡
- 不做视差、不做装饰性动画

## 6. 布局与导航

- **单栏长文**：居中正文列（max-width 约 720px）
- **右侧浮动目录**：≥1180px 视口时显示，`position: sticky` 跟随，列出四层 15 个模块，IntersectionObserver 驱动当前项高亮；点击平滑滚动跳转
- **窄屏（<1180px）**：浮动目录隐藏，顶部显示细进度条 + 一个可展开的"目录"按钮（抽屉式，列出同样的层级）
- 顶部常驻细进度条（阅读进度，砖红）

## 7. 可访问性与渐进增强

- 对比度：正文对纸底 ≥ 7:1；砖红强调色用于大字号/图形元素时 ≥ 3:1
- 滑杆为原生 `input[type=range]` + 可见标签，键盘可调
- 演示画布带 `aria-label` 描述演示内容
- `prefers-reduced-motion` 关闭入场动画（演示本身是内容，保留，但不自动播放闪烁类效果如闪电频闪）
- 语义化标签：`<article>` 模块、`<nav>` 目录、`<h1>`-`<h3>` 层级不跳级

## 8. 明确不做（YAGNI）

- 不做深色模式切换（单一杂志风）
- 不做国际化（仅中文）
- 不做服务端/构建流程/包管理
- 不做移动端手势交互（滑杆在触屏可用即可）
- 不做音频

## 9. 验收标准

1. 单文件离线打开，无控制台错误，无网络请求（DevTools Network 为空）
2. 15 个模块按模板完整呈现，每个演示可拖参且实时响应
3. 演示帧率：活跃演示达到上限（2 个）时，DevTools Performance 面板实测主线程帧耗时 ≤ 16ms（中端独显/核显基准由实现时记录）
4. 窄屏（375px）下布局不破、目录抽屉可用
5. `prefers-reduced-motion` 下无入场动画
6. 中文排版符合习惯（中英文间空格、全角标点）
