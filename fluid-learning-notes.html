一、总纲：流体不是东西，是场

不追踪每一滴水，而是把空间切成网格，每个格子记录一缕"风"（速度向量），让固定流水线每帧轮流上场。

  • 粒子法（拉格朗日）：跟着每滴水旅行（点在动）。Niagara 普通发射器属于这类。
  • 网格法（欧拉）：站在每个格子看天气（格子不动，读数在变）。FluidNinja / Niagara Grid 2D 属于这类。
  • 流体的全部状态 = 两张表（场）：速度场（每格一个箭头）+ 染料场（每格多少墨）。
  • 格子像 LED 大屏的像素：焊死不动，亮度和颜色（数值）在变——"流动"是数值分布的挪位（人浪），没有任何东西真的在移动。
  • 判断 Niagara 形态：数据在 Particles 里 = 粒子法；数据在 Render Target / Grid Collection 里 = 网格法。

核心循环：速度场搬运染料，物理规律修正速度场。

二、一帧流水线（三步 + 调味）

① 注入 → ② 配平 → ③ 平流（搬运）→ 下一帧……（每秒 60 圈）

① 注入（外力点火）

在某点注入速度，全场每个格子独立计算"我离注入点多远 → 按高斯折扣分到多少力 → 加进自己"。

两个旋钮： - 力度：这次划水多大劲（乘在最前面，全体按比例） - 半径：折扣表多慷慨（半径小=针刺，大=船桨划水）

手算例（3 格 A/B/C，注入向右力度 2，折扣 100%/10%/10%）：

注入后速度：A 0.2 →   B 2.0 →   C 0.2 →

墨同理：B 得 1.0，A/C 各 0.1。

要点： - 格子之间从不通信，各算各的（GPU 并行） - 注入点影响的是场，不是直接推别的点——一切影响经场中转（点→场→点，没有点对点直连） - 你的输入只是"愿望"，配平把它修正成"物理允许的事"

② 配平（压力投影）——算法的心脏

查账（差异/散度）：水不可压缩 → 每格"流入 = 流出"。盯"格子之间的门"：

手算例（延续上面）：

格子 收进 送出 账
A 0（左墙） 0.2 亏 0.2
B 0.2 2.0 亏 1.8
C 2.0 0（右墙） 盈 2.0

亏空=水凭空消失、暴涨=凭空变多——物理不允许，必须修。

修法（压力迭代 / Jacobi）：一条蠢规则刷 20~40 遍：

p[自己] = (p左 + p右 + p上 + p下 − div) / 4
  • "我 = 邻居平均 − 我的账"
  • 没有总指挥：每个格子只看邻居微调自己（像全班排队，每人只看左右邻居，几十轮后全场自动排齐——秩序从局部规则涌现）
  • 一轮配不平（牵一发动全身），所以迭代；游戏敢只刷 20~40 次（"几乎平"视觉上已是水）
  • 热启动：上一帧压力留 80% 当起点（趋势有惯性，收敛快）

执行（梯度减除）：u = u − ∇p（逆着压力差修速度）。修正后散度=0 ✓。

手算例修正结果（示意）：B 2.0 → 1.3，A/C 0.2 → 0.55（B 多余的速度被分还给两边——你注入的是冲劲，水表现出的是被摊匀的合法状态）。

③ 平流（半拉格朗日 · 惯性搬运）

平流 = 墨被风带着晕开——像一滴墨滴进水里，云雾一样慢慢散出去。

算法的问法是反的：不问"我的东西去哪"，问"谁流进了我？它上次在哪？"——沿自己的速度倒退一步，去上游把旧值抄回来。

手算例（dt=0.5 秒）：

C 的墨：速度 0.2 → 倒退 0.1 格 → 落在 B、C 之间（一成靠 B、九成靠 C）
        新墨 = B 的墨 1.0×10% + C 的墨 0.1×90% = 0.19  ← 墨涌进 C ✓
B 的墨：速度 2.0 → 倒退 1 格 → 正好落在 A 的格心
        新墨 = A 的墨 0.1  ← 大墨团走了 ✓
  • 倒退抄值 = 稳定的来源：正着"撒"会撒丢（质量不守恒、爆掉），倒着"抄"永远只是取一个数
  • 平流每帧产出两张新表：新速度（风运风=惯性延续）+ 新墨（墨搭风的车）
  • 墨自己没有惯性，有惯性的是风；惯性认"此刻的速度"，不认"初始速度"（滚动惯性）
  • 惯性不存储、每帧实时从场现读现用——所以实时交互零延迟、衰减才能逐帧折损它
  • 平流不问风的来历（快递员不管包裹为什么寄）——有风就搬

配平 vs 平流：推歪-扶正的搭档

平流：搬家 → 造出新差异（弄乱）    ← 内生的乱（家里人走动碰乱东西）
配平：解压力 → 熨平（整理）        ← 保洁员，见乱就整，不问谁弄的
每帧循环，谁也不闲着
  • 新差异 ≠ 新的注入（它是平流的副产品，场内部自己长出来的）
  • 新差异解出新的压力（差异是题目，压力是答案——不是"就是"）
  • 注入只需点火一次，环靠"平流造乱、配平熨平"自我维持
  • 配平不消耗能量（重新分配），衰减才消耗（真实折损）
  • 配平管"像不像水"，衰减管"什么时候停"

衰减（寿命）

每帧 值 /= (1 + 衰减×dt)。烟大、墨 0、水微小。是美术参数不是物理。

三、因果环（整套算法的世界观）

在某一点注入速度，场会在空间上产生差异；差异解出压力，压力化为流动，流动搬运一切、又制造新的差异——流体的全部现象，就是这个循环的持续运转。

注入（点火）→ 差异（出题）→ 压力（解题）→ 修正 → 平流（惯性搬运+弄出新乱）→ 新差异 → ……循环

三种结局：

情形 结局
点火一次 + 有衰减 能量磨光 → 回到全零空转（湖面复静）
点火一次 + 无衰减 近乎永转
持续点火 永动（河流进水口、火焰火源——每帧注入）

全零时循环照转，只是空转（平流=每格抄自己）。循环一直在转，注入决定它空转还是实转。

类比（湖与河）：湖面静=账平；高低落差=差异；水往低处流=压力驱动；上游来水=注入；压力释放口=outflow。浅水方程模型甚至直接拿"水面高度"当压力。

四、纳维-斯托克斯方程（符号表 + 中文注解版）

∂u/∂t = −(u·∇)u − (1/ρ)∇p + ν∇²u + f
∇·u = 0
符号 读法 意思 对应概念
∂u/∂t u 对 t 的偏导 速度随时间的变化 这一帧速度怎么变
u 速度场 每格的箭头 风
∇ nabla 梯度算子(∂/∂x, ∂/∂y) 差异探针
−(u·∇)u 平流项 风运风 平流（惯性）
(1/ρ)∇p 压力项 压力差推动 配平产生的流动
ρ rho 密度（常数） 比例系数
∇² 拉普拉斯 和邻居平均差多少（抹平倾向） 抹平器
ν nu 运动粘度 （游戏扔掉此项，数值耗散免费送）
f 外力 外界加的力 注入

五、涡流（已完整学完 ✅）

涡是什么：格子里的水原地打转

测量工具：想象放一个小桨轮（十字叶片）在格子里，看它转不转、往哪转、转多快。

旋转场的布置（顺时针）：

上邻 →(+1,0)   右邻 ↓(0,−1)
左邻 ↑(0,+1)   下邻 ←(−1,0)

涡度公式（全是减法/差分）：

涡度 =（右的竖直 − 左的竖直）−（上的水平 − 下的水平）
手算：=(−1−1)−(1−(−1)) = −4  → 负=顺时针，绝对值=强度

对照（齐步流，全往东）：=(0−0)−(1−1)=0 → 直流无涡。这就是"流动"和"旋转"的数学分界线。

涡的出生：剪切搓的

  • 剪切：相邻两层以不同速度滑动、错开（词源=剪刀两刀片错动）。画面：推一叠扑克牌，上层快下层慢，层间错开。
  • 准确方向关系：剪切 = 速度差出现在垂直于流动方向上（并排两股一快一慢）；速度差出现在沿流动方向（前后快慢）= 散度（拉伸/泉眼）。
  • 族谱：速度差（空间不均匀）→ ①纵向（同向不均）→散度→压力管账；②横向（剪切）→涡度→涡。
  • 拖动出涡：手指路径=快带，两侧慢水 → 上下两条剪切线 → 涡出生在剪切线上（不在路径中央），两排转向相反。画圈=快带首尾相连全同向搓 → 合成大涡。

涡怎么被看见：墨搭车显影

墨没有腿，每帧搭当地风的车；旋转场的风方向一直在变 → 墨被掰弯走出圆圈。一团墨因内外侧每帧被带方向略有差异 → 被拉成长条 → 卷成螺旋丝。没人画螺旋，螺旋是搬运的副产品。（= 搅咖啡奶沫卷出旋涡花纹。）

涡的一生

出生（剪切搓）→ 成形（平流搬运拉伸卷紧）→ 维持（惯性：涡是速度场的形状，
自己搬运自己）→ 衰老（两种摩擦：衰减折损 + 插值模糊专磨小尺度）
→ 死亡（能量耗尽）→ 续命（涡度约束，见下）

涡度约束（续命药 · 非物理补丁）

  • 公式：补力 = ε·(∇|ω| × ω)——用叉积（不是点乘！叉积天生给出垂直方向=旋转切线方向）沿"更强涡"的方向给切向补力。
  • 算法身份：不在原版方程里；实现为 f 的一项（f 总 = 你的注入 + 涡度补力），位置在①注入之后③配平之前（所有改速度的步骤都要在配平前完成）。
  • Niagara 里：Apply Forces 阶段的一个模块，每帧一次（帧循环），不像压力那样帧内迭代 N 次——它是显式开药方，不用逼近。
  • 续费不是偿还：补力 ∝ 当前涡度（正反馈：强→多补→更强），不是"补回衰减掉的量"。正反馈 = 灵之处，也是"过咸"（滑块 50 病态自增强）的原因。
  • 只能扶不能生：画面静止时它无事可做；造涡永远靠注入制造剪切。
  • 滑块手感：0~5 蜂蜜熔岩 / 15~25 烟的自然区间 / 30~40 湍流噪波 / 50 过咸。

能量级联（小强度两个大涡 vs 大强度满屏噪波）

  • 小强度：数值磨耗像筛子磨掉小涡，只剩大涡（一两个优雅旋涡）；
  • 大强度：①筛子失效小涡全活 ②大涡边缘本身就是剪切线→搓出新小涡→小涡边缘又搓更小的……能量从大尺度传向小尺度（级联全开）③约束本身注能过量；
  • 噪波感 = 小尺度+高密度+随机+长寿。

七、概念纠偏档案（一路踩过的坑，最珍贵的部分）

曾经的误解 真相
"差异就是平流" 差异是配平的题目；平流是搬运，在环的第四节。原句现象对、标签错
"平流是初始速度和方向" 那是注入的风。平流=用现成的风搬东西（风靠自己惯，墨搭风的车）
"平流是粒子运动的过程" 没有粒子动，是数值人浪：格子原地不动抄上游的数
"粒子因初始惯性流动" 风有惯性（滚动的），墨没有惯性（被搬的）——"初始"改"此刻"
"惯性是记录下来的" 惯性不存储，每帧从场现读（速度场的当前值就是惯性）
"新的差异=新的输入" 新差异是平流弄出的内生的乱，不是外部注入
"新的差异就是新的压力" 差异出题，压力解题——"解出"不是"就是"
"平流=配平现象" 两个不同步骤：配平=熨平（整理），平流=搬运；顺序：先配平再平流
"场是根据点的移动来的" 半拉格朗日每帧每格临时雇一个"替身点"倒退一步——借用点的视角，不追踪点
"风是具体的东西" 风不是实体，是流动本身；速度场每帧被"注入+压力+平流"现做

最终世界观定稿：

流体是场：外力注入速度 → 空间差异逼出压力 → 压力投影塑造合法流动 → 速度场平流自己和乘客 → 新差异 → 循环，衰减定终局。 注入给惯性，平流花惯性，衰减收惯性。

八、公式版算法（可复制）

见教学页第 8 章与附录，或直接用极简版：

① u += f                                    （注入）
② 涡度补力: u += ε(∇|ω|×ω)dt               （续命，可选）
③ div = (R−L+T−B)/2                         （查账）
④ p = (四邻p之和−div)/4  ×N 次               （解题，热启动 p×0.8）
⑤ u −= ∇p                                   （修正）
⑥ u,d = 旧场在 (x − dt·u) 处的插值           （平流：倒退抄值）
⑦ u,d /= (1+k·dt)                           （衰减）
